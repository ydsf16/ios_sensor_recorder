# 分辨率切换时帧率随动（2026-10-30）

Standard 设置改为按镜头组合、新分辨率查询 SDK 可选帧率，再验证联合配置。当前帧率仍可用时保留；否则按现有策略优先匹配最接近的较低可用帧率，没有较低选项时使用最低可用较高值，上限仍为 60fps。检测完成后同步更新帧率显示、两个菜单和保存状态，不弹出自动调整确认。

分辨率、帧率菜单在检测期间暂时禁用，避免尚未完成的旧草稿与新分辨率混用。镜头组合/分辨率不变时，显式帧率或曝光修改不会触发额外自动降帧。

回归用例：Wide + Ultra Wide 从 640×480@60 切至 3840×2160，确认自动选择 30、菜单不再包含 60、无配置错误弹窗，保存并录制；切回 640×480 保留可用的 30，再手选 60，重复两轮。

验证状态：iOS build-for-testing 通过；17 项 SDK 范围、帧率上限与随动排序检查通过；新版安装至 iPhone 12。用户授权后，指定的 640×480@60 → 4K@30 → 640×480 联动路径已在 iPhone 12 上两轮通过，含保存与录制；全设置遍历仍在进行，尚未宣称全量通过。原设置备份保存在 `.codex-baseline/resolution-follows-rate-validation/settings-before/`。


## 全选项扩展验证范围

- Standard：从真机设置菜单枚举全部相机组合、分辨率、帧率；逐项检查可选值、分辨率切换的自动匹配、保存状态、无配置错误提示，并对各分辨率保存录制。
- ARKit：帧率菜单改为按照所选分辨率对应 SDK 格式的最高原生帧率限制目标录制帧率。保留已有低帧率采样策略，上限仍为 60；不再把不支持该目标帧率的分辨率与 60Hz 混用。分辨率选项也只取 SDK 格式，不插入设备未支持的旧保存值。
- 其他：全部曝光时间选项、自动曝光开关、手动对焦端点/中点与自动模式、六种传感器开关保存、无 LiDAR 设备的禁用状态、付费入口及免费时长限制、中英文显示。
- 连续滑块不可能枚举所有实数位置，因此使用端点和中间值；未执行实际购买，不修改账号权益。iPhone 16 不参与本轮。

首轮全选项脚本在对无需滚动的菜单执行拖动后误选并退出，该轮不能算作通过。后来按目标缩小范围，先复测此前失败的 61 个 Standard 录制组合，再完成 Wide 的 145 个设置选项 XCTest。结果和未覆盖范围见 `IPHONE12_TARGETED_VALIDATION_2026-11-01.md`。
